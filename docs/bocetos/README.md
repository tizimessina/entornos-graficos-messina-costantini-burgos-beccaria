# Bocetos de diseño

Documenta las cuatro etapas sucesivas e incrementales del diseño visual exigidas por la
Guía Web (informe, punto 7), para al menos una página mostrando su evolución completa:

| Carpeta | Etapa | Qué va acá |
|---|---|---|
| `01-wireframes/` | i. Estructura de páginas | Dibujos lineales, sin color, de las 10 páginas del punto 5.b |
| `02-bocetos/` | ii. Bocetos | Mockups digitales con color, tipografía e imágenes (Figma) |
| `03-prototipo/` | iii. Borradores | Capturas o export del prototipo navegable |
| `04-maqueta/` | iv. Maqueta web | Capturas de la maqueta Bootstrap con contenido real, previa a la integración con PHP |
